## Thesis note

Family-based scoring prevents correlated CET1, Tier 1, and relative indicators
from counting the same capital weakness repeatedly. It also avoids treating
descriptive EBA asset-share dashboard buckets as independent distress
evidence, while retaining them as within-family signals. The family maximum
and severity mapping were fixed a priori before event data existed, so later
event evaluation will test the rule rather than tune it.
